##  Acerca del Proyecto

**AIXUS** es un simulador interactivo en tiempo real diseñado en **React, TypeScript y Vite**. El proyecto combina la simulación de mecánicas celestes con un potente motor gráfico capaz de renderizar **más de medio millón de estrellas reales** de nuestra galaxia de forma fluida directamente en el navegador web.

###  Características Principales
* **Laboratorio de Simulación Física:** Herramientas avanzadas para interactuar con órbitas, gravedades, masas y propiedades físicas de cuerpos celestes en tiempo real.
* **Catálogo Galáctico Masivo:** Renderizado optimizado de más de 500,000 estrellas basado en datos astronómicos reales.
* **Gráficos de Alta Fidelidad:** Texturas detalladas, telemetría orbital y un entorno 3D totalmente inmersivo y responsivo.
* **Ejecución 100% Autónoma:** La aplicación corre por sí misma en el lado del cliente (Client-Side) utilizando el procesador gráfico local, sin depender de APIs o servidores externos.

##  Ejecución Local

Sigue estos pasos para arrancar el simulador de forma nativa en tu computadora:

###  Prerrequisitos
* Tener instalado **Node.js** (versión 18 o superior recomendada) o **Bun**.

### 🔧 Pasos para Iniciar
1. **Instalar las dependencias del proyecto:**
   ```bash
   npm install
   ```
   *(Si utilizas Bun, puedes ejecutar `bun install`)*

2. **Iniciar el servidor de desarrollo local:**
   ```bash
   npm run dev
   ```

3. **¡Listo!** Abre tu navegador en la dirección local que te indique la terminal (usualmente `http://localhost:5173`) para explorar el laboratorio espacial.
